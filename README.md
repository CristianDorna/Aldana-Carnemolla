# Aldana Rocío Carnemolla — Psicóloga

Sitio web personal de Aldana Rocío Carnemolla, licenciada en Psicología. Presenta información sobre el espacio terapéutico, frases de Sigmund Freud y vías de contacto para atención presencial y virtual.

## Archivos

- `index.html`: estructura y contenido del sitio.
- `styles.css`: estilos y diseño adaptable a dispositivos móviles.
- `script.js`: interacciones, animaciones y frases.
- `flor-aldana.png`: ilustración floral con fondo transparente utilizada en la portada.

## Cómo verlo localmente

Abrí `index.html` en un navegador. No requiere instalar dependencias ni compilar archivos.

## Publicación en GitHub Pages

1. Subí los archivos del proyecto a la rama `main`.
2. En GitHub, abrí **Settings → Pages**.
3. En **Build and deployment**, elegí **Deploy from a branch**.
4. Seleccioná la rama `main` y la carpeta `/ (root)`, y guardá los cambios.
